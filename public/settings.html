📝 Prompt 模板（全局生效，不区分角色）

只在故事模式发送（故事对话、小总结、剧情总览）；网聊模式下的聊天、小总结、对话总览都不发送这段前置文本。

0 / 200　故事模式下所有角色共用。生成小总结时 AI 会自动从元交流中提炼并追加，你也可以在这里增删修改；建议每条 20 字内，总量上限 200 字，超出无法保存。

0 / 200　网聊模式下所有角色共用，和故事模式的附加要求互相独立。规则同上。

⚙ 对话功能 · API 设置（全局生效，不区分角色）

通用 OpenAI 兼容接口配置，支持任意兼容平台（OpenAI / DeepSeek / 各类中转等）

填到 /v1 为止即可，程序会自动拼接 /chat/completions。点右侧 ▾ 可选择保存过的地址，会自动填入对应的密钥

填好 URL / Key 后可以点"加载模型"拉取该平台支持的模型列表，选一个自动填进上面的输入框；也可以不点，直接手动填模型名

开启后聊天发的图片会直接发给模型看；关闭（默认）时图片只显示在聊天窗，实际发送给AI 的是前缀图片+文件名，适合不支持识图的模型
